# 🤖 Missões JARVIS

Projeto pessoal desenvolvido durante meus estudos de Python, inspirado no assistente JARVIS do Homem de Ferro.

## 🎯 Objetivo

Aprender programação na prática, desenvolvendo lógica, organização de código e funcionalidades para um assistente pessoal.

## ⚙️ Funcionalidades

- Sistema de missões interativas
- Perguntas e respostas
- Sistema de pontuação

## 🧰 Tecnologias

- Python 3
